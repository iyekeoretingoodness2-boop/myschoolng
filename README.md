# Goodness Digital Service

A mobile-friendly public landing page for digital-skills training and services.

## Current website
- Responsive landing page branded Goodness Digital Service
- Six free-to-explore learning topics: ChatGPT and AI tools, AI video creation, AI image generation, flyer and graphic design, social media content, and digital creator workflow
- Course outline popups and WhatsApp contact link
- No payment flow, payment instructions, account registration, or payment approval flow
- No build step required; the site is a static `index.html`

## Important limitations
This is a static front-end website. The course cards currently show learning outlines, not hosted lessons. It does not yet have secure user accounts, cross-device progress, admin dashboard, private messaging, community chat, or course uploads. Those features require a properly configured backend and should not be represented as live until implemented and tested.

## Publish
The site can be hosted on any static website host. GitHub Pages must be enabled in the repository settings before a live URL is available.
